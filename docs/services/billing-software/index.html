FAQ

Good questions

Does it need internet?

No. The software runs fully on your computer. Internet is only needed if you switch on the optional Google Drive / Sheets copy.

Is there a monthly fee?

The desktop licence is a one-time purchase for the computer it is activated on. Support, customisation and extra computers are quoted separately.

Can I try it first?

Yes. It installs with a short free trial. After that you get an activation code from us to continue.

Can it be customised for my trade?

Yes. The same base has been built for computer shops and jewellers. New fields, reports or print layouts are quoted as custom work.
